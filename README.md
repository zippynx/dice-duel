# 🎲 Dice Duel

A sleek and modern dice battle game built using pure HTML, CSS, and JavaScript.

## ✨ Features

- Smooth dice rolling animation
- Elegant luxury-inspired UI
- Responsive design for desktop & mobile
- Dynamic winner detection
- Clean and minimal code structure

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

## How to Play

1. Open the game in your browser
2. Click the **Roll** button
3. The player with the higher dice wins
